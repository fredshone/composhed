# CEMDAP-aligned variant

**Code:** `composhed/cemdap/`, which builds on `composhed/common/` (see [what the source-aligned variants share](source_aligned.md))

CEMDAP (Bhat et al., 2004) builds a person's day in continuous time, one
decision after another. This variant follows the same order:

1. Does the person go to work or school today?
2. If so, when do they start, and how long do they stay, given that start?
3. How many stops do they make on the way there, on the way back, and on
   separate trips from home before and after?
4. What type is each stop, and how long does it last?
5. How long do they stay at home between trips?

People with no work or school get a separate chain: how many trips from home,
when they first leave, and how many stops on each trip.

Start times and durations come from hazard-based duration models
(accelerated failure time, AFT). Each draw is limited to the time still free,
so the day cannot overflow.

## Running it

```bash
uv run composhed-train-cemdap --attributes A.csv --schedules S.csv --output-dir models/ --seed 0
uv run composhed-generate-cemdap --attributes A.csv --models models/cemdap_models.pkl \
    --out-attributes syn_a.csv --out-schedules syn_s.csv --seed 0
```

This variant takes only the [shared options](source_aligned.md#running-them).

## Inputs

All eight person attributes, one-hot encoded with the first category dropped,
as in the [compositional baseline](compositional.md).

## Components

"Fidelity" says how closely each component follows CEMDAP:

* **full:** same structure and model form;
* **simplified:** same idea, reduced form;
* **absent:** not modelled.

| CEMDAP component | What it decides | Model | Code | Fidelity | Notes |
|---|---|---|---|---|---|
| Work / school participation | Whether the day has work, or (failing that) education | Two binary logits | `models.CemdapModels.work`, `.edu` | simplified | No household context. Work and education on the same day are merged into one mandatory activity (11 NTS tours). |
| Work / school start | Start time, measured as minutes since 03:00 | AFT; log-logistic or Weibull, chosen by AIC | `.start` | full | |
| Work / school duration | Duration given the start time | AFT with start and start² as covariates | `.duration` | full | |
| Stops by position | Number (0–3) of outbound stops, inbound stops, trips before and trips after | Four ordered logits | `.counts` | simplified | CEMDAP generates stops by period of day; here they are generated by position relative to work / school. |
| Non-worker pattern | Number of trips from home (0–4) and stops per trip (1–4) | Ordered logits | `.nm_tours`, `.tour_size` | simplified | Trips are plain lists of stops, with no main activity. |
| Stop type | escort, leisure, other, shop or visit | Multinomial logit on position, stop number and remaining time | `.stop_purpose` | full | |
| Stop duration | Minutes per stop | AFT per stop type, drawn within the remaining time | `.stop_duration[type]` | full | |
| Home stays | Time at home between trips, and first departure on a day with no work or school | AFT. The first home stay of a work / school day and the last home stay of every day take whatever time is left. | `.home`, `.first_departure` | simplified | |
| Keeping the day feasible | | Bounded draws, then up to 50 redraws of the person, then a counted last-resort rescale | `chain.CemdapChain` | full | |
| Location, mode, travel time | | — | — | absent | Not in the data. |

### How a day is built

**Work / school day:**

1. Draw the start *S* and the duration *D*, bounded so the day can still close.
2. Draw the stop and trip counts, each capped at what can still fit.
3. Fill the morning (*S* − 1 minutes available): outbound stops, then each
   earlier trip with its stops followed by a home stay of at least 10 minutes.
   The first home stay of the day takes what's left.
4. Fill the evening (1440 − *S* − *D* − 1 minutes available) the same way:
   inbound stops, then each later trip preceded by a home stay. The last home
   stay takes what's left.

**Day without work or school:** draw the number of trips, then the first
departure, then the trips and the home stays between them. The last home stay
takes what's left.

**Bounds on every draw:** each draw leaves room for everything still to come,
which is 1 minute per remaining stop, 10 minutes per remaining home stay and 1
minute for the final home stay. The remaining-time covariates used in training
are computed in the same order.

## Calibration

[Shared method](source_aligned.md#calibration).

**What is adjusted:**
* the constants of the participation logits, the four position-count models,
  the trip-count and stops-per-trip models, and the stop-type model;
* the AFT locations for work / school start, work / school duration, stop
  durations by type, home stays and first departure;
* the AFT scales for work / school start and duration.

**What is matched:**
* the share of people in each outcome;
* mean durations and start times;
* for work / school start and duration, the gap between the 10th and 90th
  percentiles.

## Deviations from CEMDAP

* **No locations, modes or travel times.** Moving takes no time; the only cost
  of a trip home is the 10-minute minimum stay.
* **Coefficients are re-estimated on NTS**; no CEMDAP coefficients are used.
* **One person-day, not a household day**: no joint activities.
* **One mandatory activity per day**, as in the compositional baseline. Later
  work or school trips are folded in (see [tour_rules.md](tour_rules.md)).
* **Capped choice sets:** at most 3 stops per position, 4 trips on a day
  without work or school, and 4 stops per trip. Larger counts are logged.
* **Stops by position, not by period of day.**
* **Very early starts are clipped.** Work / school starts before 03:00 are
  clipped to 03:01 so they fit the model's clock (39 NTS episodes).
* **Own estimation code.** The logits and ordered logits use the repository's
  own L-BFGS code (`common/choice.py`, same likelihood as statsmodels but much
  faster). The AFT models use custom maximum likelihood (`common/hazard.py`).
* **Calibration is an extra stage.** CEMDAP's published models have no
  equivalent.

## Ablations

| Switch | Effect |
|---|---|
| `--no-calibrate` | Estimation only. |
| `--independent-timing` | Work / school start from a kernel density estimate per employment category, and duration from a log-normal regression that ignores the start time (compositional style). |
| `--consistency rescale` | Durations are drawn without bounds; a morning or evening that overflows is shrunk proportionally (counted). |

## Outputs

The [shared outputs](source_aligned.md#outputs) (`models/cemdap_models.pkl`,
`validation.json`, `generation_report.json`). `validation.json` also records
the 5th percentile of observed home stays between trips
(`info.between_tour_home_p05`), as a check on the 10-minute minimum.
